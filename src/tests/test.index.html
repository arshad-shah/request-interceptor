Request Interceptor Test Suite

Setup Instructions

  1. Install/update your Request Interceptor extension
  2. Open the extension panel
  3. Enable the interceptor
  4. Configure test routes using the examples below
  5. Open browser DevTools (F12) to see console logs and network activity

1. Basic Request Interception

Configuration: Add route GET /api/test with status 200 and response: {"message": "Hello from interceptor!"}

2. Response Headers Testing

Configuration: Add route GET /api/headers-test with response headers:
• X-Custom-Header: CustomValue
• Cache-Control: no-cache
• Access-Control-Allow-Origin: *

3. Request Headers Testing

Configuration: Add route POST /api/auth-test with:
Response: {"message": "Headers modified", "success": true}
Request Headers:
• Authorization: Bearer test-token-123
• X-API-Key: test-api-key
• X-Custom-Header: added-by-interceptor

4. Remove Request Headers Testing

Configuration: Add route GET /api/remove-headers-test with:
Response: {"message": "Headers removed", "success": true}
Remove Request Headers:
• Authorization
• User-Agent
• X-Remove-Me

5. CORS Headers Testing

Configuration: Add route OPTIONS /api/cors-test with response headers:
• Access-Control-Allow-Origin: *
• Access-Control-Allow-Methods: GET, POST, PUT, DELETE
• Access-Control-Allow-Headers: Content-Type, Authorization

6. Performance Testing

Configuration: Add routes with different delays:
• GET /api/fast - 0ms delay, response: {"speed": "fast"}
• GET /api/slow - 2000ms delay, response: {"speed": "slow"}

7. Error Scenarios Testing

Configuration: Add error routes:
• GET /api/404-test - Status 404, headers: X-Error: Not Found
• GET /api/500-test - Status 500, headers: X-Error-ID: ERR-123

8. DevTools Inspection

What to Check in Browser DevTools:

  • Console Tab: Look for "[Request Interceptor]" logs showing header modifications
  • Network Tab: Check if requests show "X-Request-Intercepted: true" header
  • Network Tab: Verify response headers match your configuration
  • Network Tab: Confirm request headers were modified/removed as expected
