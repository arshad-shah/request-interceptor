About Request Interceptor

This extension allows you to intercept and modify API requests for UI testing purposes.

Use it to test different response scenarios without changing your backend code.

Quick Tips

  • Enable the interceptor using the toggle in the header.
  • Add routes to intercept specific API endpoints.
  • Use the floating button on the page to quickly access the interceptor.
  • View logs to see which requests are being intercepted.

Advanced Usage

You can use patterns in your URLs:

  • Use * as a wildcard: /api/users/*
  • Include query parameters: /api/users?role=admin

For response bodies, you can use:

  • JSON for API responses
  • Plain text for simple responses
  • HTML for rendered content
